# Multiplexed Analysis of IMC Data

**Author:** Yuval S. Kats
**Affiliation:** Hebrew University of Jerusalem (HUJI)

## Overview
Generative models for spatial proteomics using publicly available Imaging Mass Cytometry (IMC) datasets. This project uses IMC publicly availalbe datasets to enable virtual staining, and test whether genetative model are able to capture epigenetic deregulation in breast cancer using single cell technologies.
